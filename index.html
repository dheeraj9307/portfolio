About Me

Building Reliable Software from Backend to Frontend

I am a Java Backend and Full-Stack Software Engineer focused on building secure, maintainable applications. My technical experience includes Java, Spring Boot, Spring Security, REST APIs, Spring Data JPA, Hibernate, MySQL, Redis, React, and Next.js.

My enterprise project experience includes the HCL WA Plugin Factory project and the Mercedes-Benz Digital Key Core project, involving software maintenance, defect investigation, testing, and backend component validation.

Since January 2023, I have independently worked on KodeCapsule, my own full-stack developer platform. Its development includes authentication, content management, real-time messaging, notifications, moderation, and analytics.

I have also developed RAG Generator, an application that processes uploaded PDF documents and supports question answering using retrieval-augmented generation. It combines Python-based APIs, document processing, vector search, and LLM integration.

I value clean code, object-oriented design, API reliability, automated testing, secure development, and practical problem-solving.
